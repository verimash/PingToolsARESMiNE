# [неактуально] Чиним пинг на сервере ARESMiNE!
#### Программа работает путем ручного прописывания ближайшего фильтрующего сервера TCPshield в обход проблем с маршрутизацией. Проблема возникает из-за ~экономии провайдеров~ перегрузки магистральных линий, из-за чего трафик идёт не должным образом. Второй возможной причиной может стать проблема с DeepPacketInspection.
#### Работает на базе ~говнокода~ Java (хотя можно было и однострочник на Python написать, мда) 
#### Инструкция по работе с программой: [перейти на пост в Telegram](https://t.me/aresmineshorts/129)
